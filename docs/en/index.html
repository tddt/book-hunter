Book Hunter is a desktop ebook library and reader for Windows. EPUB, MOBI, AZW3, PDF and TXT all land in one library and share a home-grown typesetting engine, full-text search and inline bilingual translation. Your books and notes stay on your own disk.

WHAT IT DOES

Managing books and reading them, in one place

Not the longest feature list. Just an answer to a familiar problem: you have hundreds of ebooks on disk and nowhere you actually want to finish one.

01 / FIVE FORMATS

One pipeline on import

Non-EPUB files are converted to standard EPUB and fed back through the parser for structural self-validation. Single files, batches, whole folders, drag-and-drop, double-click .epub import and SHA1 de-duplication are all supported.

NormalizedBook → buildEpub()
02 / TYPESSETTING

The text block is calculated here

No epub.js. CSS multi-column pagination keeps the text block centred and two-page spreads clipped-free, normalises cross-chapter page-turn direction, and separates real page numbers from word-count-weighted progress.

NativeReaderEngine
03 / FULL-TEXT SEARCH

Land on the exact page

An inverted index (MiniSearch) covers title, author, publisher, category and tags in milliseconds, while an interruptible streaming scan searches every chapter body. Click a hit and it opens the page containing it, highlighted.

MiniSearch + streaming scan
04 / IMMERSIVE READING

The interface gets out of the way

Toolbars hide until you approach the screen edge. Five paper themes, adjustable type size and spacing, table of contents, bookmarks, five highlight colours, notes, in-book search, fullscreen and shortcuts. Your last position is restored on reopen.

Light / dark / follow system
05 / BILINGUAL READING

Translation turns the page too

Translated paragraphs are injected into the article body, aligned to the source and sharing the same text block, type size and pagination — not squeezed into a side drawer. Three display modes, 15 target languages, selection translation, on-disk cache for offline reading.

Original + translation / either alone
06 / LIBRARY & SOURCES

The library stays yours

Category tree, multi-tags, favourites, reading status, ratings and grid/list views. Aggregates Project Gutenberg, Gutendex, Standard Ebooks, Open Library and Internet Archive, with custom OPDS catalogues and direct EPUB URLs.

Everything stored locally
THE READING ENGINE

Why build a typesetting engine from scratch

Chinese line-breaking, two-page spreads that do not clip, and a "43% through the book" you can actually trust all require full control over pagination geometry. So there is no off-the-shelf renderer: unzipping, chapter HTML sanitising, CSS multi-column pagination, cross-chapter direction handling, and page/progress mapping are all computed here.

The cost is owning every layout edge case (the README lists the degradation cases honestly). The gain is that five formats read exactly the same inside the same text block.

HONEST LIMITS

What it does not do

Stating the boundaries clearly matters more than three extra selling points. These are things the current version genuinely cannot do, or deliberately will not do.

×
No original EPUB stylesheets — kept for a consistent text block, so unusual poetry and table layouts degrade to generic typography.
×
PDF layout is not preserved — text layer only, no OCR; use a PDF reader if you need the original layout.
×
No DRM or KFX — MOBI covers MOBI6 / KF8 only; no authentication or paywall circumvention of any kind.
×
Public-domain books only — online sources are limited to public-domain or explicitly free-licensed works, no pirated catalogues.
×
Not a mobile app — "phone layout" means a responsive window at 640px or below; no mobile package, no swipe-to-turn gesture.
×
Translation has quotas — free public endpoints with rate limits; a self-hosted LibreTranslate endpoint can replace them.
GET STARTED

Two ways in

Grab a prebuilt installer, or build from source. Building needs Node.js 20+ and pnpm 9+.

# build from source pnpm install pnpm dev # dev server pnpm build # all three layers pnpm dist:dir # unpacked directory pnpm dist:win # installer + portable exe

All book metadata, progress, bookmarks, highlights, notes and cached translations live in the local library directory under %APPDATA%. Copy that one directory for a complete migration. Removing a book from the library deletes the record only, never the source file.

The installer associates only .epub and does not take over your PDF or TXT default handlers. SHA256 checksums are listed in the release notes.

FAQ

Questions you may have

Is Book Hunter free and open source?

Yes. It is MIT licensed and free of charge, with full source at github.com/tddt/book-hunter. Prebuilt Windows installer and portable builds are published on GitHub Releases.

Does it upload my books, notes or reading data?

No. There is no account and no cloud sync. Book metadata, progress, bookmarks, highlights, notes and cached translations live in the local library directory under %APPDATA%. Network access is used only for user-initiated online book downloads and translation requests.

Which formats are supported, and how good is PDF?

EPUB is stored natively; MOBI, AZW3, PDF and TXT are converted to standard EPUB on import, so they share the same table of contents, progress, search and annotations. PDF extracts the text layer only: text and images are kept but the original layout is not, and scanned PDFs need OCR first. MOBI covers MOBI6 and KF8, not DRM or KFX.

How is this different from Calibre or epub.js-based readers?

It is reader-first rather than a general conversion and device-sync suite. It does not use epub.js: pagination geometry is implemented in-house with CSS columns to control Chinese typography, two-page spreads, real page numbers and word-count-weighted progress. Every supported format flows into one EPUB-based reading pipeline.

Is there an Android or iOS app?

No. At a window width of 640px or less the interface switches to a bottom tab bar, but there is no mobile package and no touch swipe-to-turn gesture. Windows x64 is the only shipped build target.

Where do the online books come from?

Project Gutenberg, Gutendex, Standard Ebooks, Open Library and Internet Archive, plus user-added OPDS catalogues and direct EPUB links. Only public-domain or explicitly free-licensed works are included: no pirated sources, no login or paywall bypass. Built-in catalogues are mostly English public-domain books.

Can I migrate my library to another computer?

Yes. Copy the whole library directory under %APPDATA% and everything moves with it. A built-in one-click backup and restore wizard is on the roadmap but is not shipped yet.
